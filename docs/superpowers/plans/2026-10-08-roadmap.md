# Empire Ops Roadmap

**Goal:** One private, always-current view of the whole Riance LLC portfolio
(Empire Management Group, Riance Realty, Wind Fire & Water, FixIQ). It is drawn
as a neighborhood where each house is an association, paired with a plain table
and a real Florida map, and it is fed only by real, dated data.

**Owner:** JR Riestra. **Separate from Vera:** Vera is Amanda's project (Azure).
Empire Ops shares no code, database, or credentials with it.

## Rules that apply to every phase

- No figure without a source and a date. A missing number is shown as missing.
- Test associations (`communities.is_test`) are excluded from every total.
- Each association is a separate client: no view blends one association's money into another's.
- Collections, liens, and delinquency letters go to counsel. The app only flags; it never drafts collection correspondence.
- Everything the app writes for a person to send is a draft.
- People data (Phase 4) is admin-only, used for coaching, and applied the same way to everyone.
