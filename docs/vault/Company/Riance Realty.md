# Riance Realty

> [!info] Riance Realty is the real estate brokerage arm of [[Riance LLC Overview|Riance LLC]], handling sales and leasing primarily within communities managed by [[Empire Management Group]].

## Services

| Service | Description |
|---------|-------------|
| **Residential Sales** | Buy/sell within managed communities |
| **Leasing** | Tenant placement for investor-owned units |
| **Rental Management** | Lease administration, rent collection |
| **Market Analysis** | CMA reports, pricing guidance for boards and owners |
| **New Community Sales** | Developer sales support for new construction |

## Cross-Sell Synergy

> [!tip] Riance Realty has a built-in lead pipeline from EMG's 28,391 doors. Every ownership transfer, every tenant inquiry, every board referral is a warm lead.

| Lead Source | Trigger | Volume Estimate |
|-------------|---------|-----------------|
| Ownership transfers | Sale/purchase in managed community | ~200/month |
| Tenant placements | Owner needs tenant for unit | ~50/month |
| Board referrals | New resident orientation | Ongoing |
| Estoppel requests | Closing activity signal | ~150/month |
